Expense Mobile V1
- Mobile-first iPhone prototype.
- Main screen: current month transactions and remaining balance.
- Fast add transaction bottom sheet.
- Quick presets: Tennis, Taxi, Ăn uống, Shopee, Điện, Internet, Sunny, Khác.
- Manual entries persist using browser localStorage.
- Overview screen included.
- Can be added to iPhone Home Screen as a web-app prototype.
